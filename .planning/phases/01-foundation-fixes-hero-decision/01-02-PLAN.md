<export_commands>
<!-- Exact, reproducible commands. Run from the repository root. These were validated at 960w
     during planning; the 480w and 1440w rows are the same pipeline with a different scale target. -->

```bash
SRC="public/assets/about/photos/hero-bg.jpg"
OUT="public/assets/home/hero"
CROP="crop=3376:4220:0:257"
mkdir -p "$OUT"

for W in 480 960 1440; do
  H=$(( W * 5 / 4 ))
  ffmpeg -hide_banner -loglevel error -i "$SRC" \
    -vf "${CROP},scale=${W}:${H}:flags=lanczos" \
    -q:v 4 -y "$OUT/murilo-hero-${W}.jpg"
  ffmpeg -hide_banner -loglevel error -i "$SRC" \
    -vf "${CROP},scale=${W}:${H}:flags=lanczos" \
    -c:v libsvtav1 -crf 32 -preset 6 -pix_fmt yuv420p10le \
    -y "$OUT/murilo-hero-${W}.avif"
done
```

Expected intrinsic dimensions: 480x600, 960x1200, 1440x1800.
libsvtav1 prints an `Svt[info]` banner to stderr on every run — that is normal, not an error.
</export_commands>
